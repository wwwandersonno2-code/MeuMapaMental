MEU MAPA MENTAL - VERSÃO 0.1

1) Para testar sem instalar nada: abra app/src/main/assets/index.html no Chrome ou Edge.
2) Para gerar APK: abra a pasta MeuMapaMental no Android Studio com Android SDK 35 instalado, aguarde sincronização Gradle e use Build > Build APK(s).
3) APK de depuração esperado após compilação: app/build/outputs/apk/debug/app-debug.apk.

Esta entrega inclui o código-fonte e uma versão web offline. O APK NÃO está incluído, pois não foi compilado neste ambiente.
O armazenamento usa localStorage do navegador/WebView. Faça backup de seus mapas em JSON.
Limitações conhecidas: exportação SVG e JSON via downloads podem precisar de integração nativa adicional no Android WebView; o projeto não inclui colaboração online, sincronização na nuvem, nem exportação PDF.
